One endpoint

GET /api/signals

ParamWhat
qA place name, like Ludhiana
lat, lonCoordinates, instead of q
worryOptional, 1 to 10. Adds worry_vs_reality to the answer

Answers are cached about 15 minutes per ~1 km, so it is fast. Errors return JSON with error and message (400 bad request, 404 place not found, 502 data source down).


    

  

  
GET /api/headlines

    
Real climate headlines with a calm, plain-words note under each. Param: region = india (default) or world. Each item has title, source, link, topic, calm, loudness and signal. Cached about 30 minutes. Headlines via Google News RSS.

Built to be calm and explainable

  
Every answer comes from fixed, published thresholds on live data, not a black box. Levels run 0 to 3 (comfortable to severe). Language is awareness only and never medical advice. Interested in a white-label version? Reach out through Anxothotl.
